# Documentatie

De actieve projectplannen staan bewust in de projectroot, zodat het actuele
werk direct zichtbaar blijft. Onder deze map staat ondersteunende documentatie:

- `operations/`: actuele beheer- en overdrachtsinformatie.
- `reference/`: externe brondocumenten en specificaties.
- `architecture/`: doelarchitectuur, legacyregister en deprecatiebeleid.
- `archive/epics/`: implementatiedocumentatie van Epic 1–5; open validatie
  blijft in het actieve uitvoeringsplan zichtbaar.
- `archive/analysis/`: analyses die als basis voor de herstructurering dienden.
- `archive/validation/`: historische, gegenereerde validatierapporten.
